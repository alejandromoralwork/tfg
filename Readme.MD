This project consists of two parts: 

The theoretical framework and the empirical research.

In the theoretical section, I dive into the fundamentals of order book models, comparing Continuous Order Books (COB) and Frequent Batch Auctions (FBA). I also cover order matching and clearing mechanisms, alongside the mathematical definition of optimized clearing in batch auction models using common industry solutions. This provides the necessary background to get a clear, comprehensive view of the topic.


For the empirical research, I built two simulation engines to model a COB and an FBA. The goal is to feed these engines with live market data from exchanges like Hyperliquid and Polymarket, allowing me to calculate key metrics and analyze their differing dynamics. Additionally, I implemented an Automated Market Maker (AMM) liquidity provider oracle to ensure realistic market behavior.
